#Anime Agent - AI动漫信息聚合平台
项目简介

Anime Agent 是一个基于 AI Agent 与 RAG（检索增强生成）技术构建的动漫信息聚合平台，主要面向二次元用户与动漫爱好者，提供动漫简介查询、角色演员表、声优信息、用户评论总结以及相关推荐等功能。

项目旨在解决传统动漫资料查询过程中信息分散、检索效率低、社区评论内容冗长的问题。用户仅需输入动漫名称，即可在数秒内获得完整且结构化的番剧资料。

核心功能
1. 动漫信息查询
动漫简介
类型标签
上映时间
评分数据
世界观设定
相关推荐

支持快速检索热门番剧与经典动漫内容。

2. 角色 / 声优演员表

自动整理：

角色名称
声优（CV）
角色关系
声优参与的其他作品

提升动漫角色资料获取效率。

3. AI 评论总结

系统会自动分析社区评论与弹幕内容，并生成：

观众评价总结
热门剧情讨论
角色人气分析
用户情绪倾向

帮助用户快速了解作品口碑。

4. 多 Agent 协同架构

系统核心采用多 Agent 协同模式，包括：

Search Agent（搜索 Agent）
Data Agent（数据聚合 Agent）
Summary Agent（内容总结 Agent）
Recommendation Agent（推荐 Agent）

通过长链路推理完成复杂动漫信息处理。
